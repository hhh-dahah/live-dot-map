把活点地图接入你的项目

给使用 AI 编程助手(Codex / Kimi Code / Claude Code 等)的人。接入后,Agent 每次会话开始会主动汇报项目全局:当前进展、等你判断的方案、停滞的路线。

1让 Agent 全自动接(推荐)

在项目目录里对你的 Agent 说一句:

读取 https://livedotmap.top/agent-kit/setup.md 并严格执行其中的指引,把活点地图接入我当前的项目。

拉取失败?让 Agent 把网址换成 app.live-dot-map.workers.dev(挂代理时)或 test-d0gims26n5c5ce096-1425841737.tcloudbaseapp.com(国内兜底),路径不变。剩下全自动:下载画布到 ~/.live-dot-map/、建桌面快捷方式、注入协议、初始化地图、拉起画布。已有的记录文件也会一并迁移成地图草稿,你在画布上审核。

2或者手动接

① 画布:下载 app.html 放到 ~/.live-dot-map/(Windows 即 C:\Users\<用户>\.live-dot-map\),双击即开。

② 协议:打开 AGENTS.snippet.md,把全部内容追加到你项目根目录 AGENTS.md 的末尾(没有就新建一个)。

③ 地图:在项目根新建 .live-dot-map/ 目录,把 map.template.json 复制进去改名 map.json。不复制也行——下次会话对 Agent 说「初始化活点地图」,它会读你的现有记录生成草稿。

app.html画布程序本体,零依赖单文件 AGENTS.snippet.md协议段,贴入项目 AGENTS.md map.template.json空白地图模板:一条主路线 + 一个「开始」节点 setup.mdAgent 全自动接入指引(口令引用的就是这份)

3打开画布,连上项目文件夹

打开活点地图画布,菜单里选「打开项目文件夹」。之后你在画布上的改动会自动存进项目 .live-dot-map/map.json,Agent 读写同一份文件;Agent 改了,画布两秒内自己刷新。

判断权永远在你:评分你打、归档你确认、画布上随便改,Agent 下次读到的就是你的版本。

文件说明与细节见 README.md(纯文本)。本页离线可用:整个 agent-kit 目录就在你下载的活点地图里。
