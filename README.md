# 活点地图 LiveDotMap

一张适合开放式任务探索的**人机协作地图**：人提供业务上下文，Agent 在同一份项目记忆上继续探索、记录方案，并返回可审核的大节点。

在线体验：<https://livedotmap.top>

## 这是什么

做开放式任务（写方案、做调研、改产品）时，人和 AI 的对话记录往往散落在各处，过几周就再也找不回来。活点地图把「一个任务的记忆」变成一张可视化的地图：

- **项目 = 一个文件夹**：人和 Agent 的数据都保存在你选定的项目文件夹里。
- **地图 = 一个任务的记忆**：一个项目下可以有多张地图，每张地图对应一个任务；Agent 默认读写当前这张地图。
- **人审机器改**：Agent 通过本地桥在地图上增删节点、记录方案，所有改动以可审核的大节点呈现，人来打分、归档、决定方向。

## 核心特性

- 画布式地图：节点、方案箭头、便签，评分徽标与归档弱化一目了然。
- 本地桥：可靠保存、WAL 恢复、冲突检测、SSE 实时同步、确定性图检索与 MCP 工具。
- Agent 接入：内置 Codex、Claude Code、Kimi Code 适配器（`agent-kit/`），接入后 Agent 与你共用同一份本地记忆。
- 数据不出本机：地图数据默认留在项目目录的 `.live-dot-map/`，不上传项目内容。
- Windows 安装包：一键安装，桌面快捷方式启动画布，自动连接本地桥。

## 快速开始

**普通用户**：从 [GitHub Release](../../releases) 下载 `LiveDotMapSetup.exe`，安装并打开画布，选择一个项目文件夹即可开始；在画布里对 Agent 说一句 `/地图自检` 可完成接入与健康检查。

**开发者**：接入协议与适配器细节见 [`agent-kit/setup.md`](agent-kit/setup.md)。

```powershell
npm ci
npm run verify
```

`verify` 会依次运行核心测试、三浏览器强模式、降级模式、性能、三适配器模拟闭环、安装器降级入口和部署产物检查。

## 仓库结构

- `app.html` — 正式画布（单一事实源）；`canvas.html` 是冻结的验收样板。
- `src/bridge/` — 本地桥（Node）：存储、同步、MCP。
- `agent-kit/` — 各 Agent  CLI 的项目适配器与接入文档。
- `landing/` — 落地页源码（Next.js 静态导出）。
- `installer/` — Windows 安装器（WinForms）。
- `docs/` — PRD、实测记录、执行计划与交接摘要。
