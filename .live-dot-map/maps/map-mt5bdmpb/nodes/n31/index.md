# 之后日程表

现在到受理
- 第 3 天：看一次“通知书办理”。
- 第 14 天：若还没通知，再看一次。
- 可能收到《受理通知书》：说明系统正式给了申请号和申请日。
- 极少数情况下会收到《不予受理通知书》：不要自己重传，直接把通知书发我判断怎么补救。
收到《受理通知书》后
- 当天或次日打开“缴费服务 → 应缴费查询”。
- 缴申请费、公布印刷费；你已提交实审请求，建议把实审费也一起缴清。
- 最迟不超过今天起第 60 天完成申请阶段缴费；通知书出现后就不要拖。
- 缴费成功后保存缴费记录/截图即可。
这一步办完，暂时又不用操作了。申请费、公布印刷费的法定期限是申请日起两个月内或收到受理通知书后 15 日内；实审费最晚三年，但你要尽快审，就跟前两项一起缴。CNIPA 缴费规则
初步审查与提前公开
你已经勾了提前公开。后续可能有两种情况：
- 没有通知：代表仍在正常处理，继续等。
- 《补正通知书》：通常是格式、手续、文件完整性、编号等能改的小问题，不等于专利被否定。
收到补正通知书时：
- 当天把完整通知书发我；
- 看通知书写的答复截止日；
- 我们只针对它指出的问题提交“补正书＋替换页”；
- 不擅自加新技术内容，也不随便重写整份专利。
逾期不答复，申请可能被视为撤回；补正必须围绕通知书问题，不能超出原始说明书和权利要求书记载的内容。CNIPA 初审与补正规则
实质审查
公开后才会真正进入实审。这里也有两种主要情况：
- 没有通知：正常排队审查，不用做事。
- 《审查意见通知书》：审查员开始问技术问题，例如“是否有现有技术”“创造性够不够”“权利要求是否清楚”。
收到审查意见通知书时：
- 不要自己立刻承认、删权利要求或上传新文件；
- 把通知书发我；
- 我们先查它引用的对比文件，再决定解释、修改哪些权利要求；
- 仍以通知书给的截止日为准。
它不是“失败通知”，而是正式审查中很常见的一轮问答。
最终可能结果
- 最好结果：《授予专利权通知书》＋《办理登记手续通知书》
  收到后两个月内，按通知书缴授权当年年费等费用；缴完后才会授权公告、发电子证书。这个阶段通常不用再交一堆材料，主要按通知书缴费即可。CNIPA 授权办理说明
- 不理想结果：《驳回决定》
  不等于马上没了。收到后先发我；如确有理由，可以在通知书期限内考虑复审。不要自行放弃。
