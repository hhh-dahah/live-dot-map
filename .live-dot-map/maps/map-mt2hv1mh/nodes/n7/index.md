# 卡片动态更新 + 人机双写极端场景

卡片上只记三样：路径 + 摘要 + 指纹（指纹 = 文件修改时间 + 大小 + 内容哈希）。

   • 保存时顺手刷：人保存 → 刷这张卡（v7 我们已经有「人类保存 hook」了，正好挂这
     ）；Agent 写 → 也刷这张卡。双写全覆盖。
   • 查询时先对指纹：Agent 来查 → 卡片指纹 vs 文件当前指纹，对不上就现场重读这一张（只刷
     这一张，不是全馆重建）。
   • 创建节点时就有卡片：建节点 = 建 index.md（v7 已做）+ 同刻建一张空卡片（标题=节点名
     ）。不存在「有节点无卡片」状态。
   • 极端场景兜底（你用外部编辑器绕过桥改了文件、桥崩了、断电）：全都靠指纹校验——只要查
     的时候对不上就重读。最坏结果只是「第一次查稍慢一点」，永远读不到旧内容。
