# 前端实现方案一：极简纯净沉浸派（The Minimalist Zen）
> **灵感来源**：Notion、Typora、iA Writer、Bear  
> **设计哲学**：**“退后一切 UI，把 100% 视界与呼吸感留给思考与文字”**  
> **对应分支**：`ui-exp-minimal-zen`

---

## 二、关键组件与交互规格

### 1. 行号槽：彻底移除
- **规范**：移除 `mdv-gutter`，取消 46px 强占宽度。
- **版心约束**：编辑区设置 `max-width: 820px; margin: 0 auto;`，文本居中呼吸感，彻底摆脱“程序员代码编辑器”的压迫感。

### 2. 资料包右侧栏：无级自由拉伸 + 磁吸贴边收起
- **Splitter 分割手柄**：
  - 宽 4px，实际可见为 1px 淡灰发丝线（`var(--border)`）；
  - `cursor: col-resize`；
  - 悬停或拖拽时激活 `--accent` 浅紫蓝微光晕；
  - **自由拉伸范围**：`0px ~ 480px`；
  - **磁吸收起（Snap to Zero）**：当用户向右拖动至宽度小于 `50px` 时，弹性吸附贴边变为 `0px`（完全展开编辑器到 100%）；
  - **双击复位**：双击分割线，在记忆宽度（如 `220px`）与 `0px` 之间平滑动画切换（`transition: width 0.2s cubic-bezier(0.16, 1, 0.3, 1)`）。

### 3. 人机笔迹识别渲染（基于 `<!-- @author: ... -->`）
- **Markdown 存储**：
  ```markdown
  <!-- @author: human -->
  人类写的内容……

  <!-- @author: agent:antigravity -->
  Agent 输出的内容……
  ```
- **渲染规则**：
  - 遇到该注释，DOM 中不渲染注释文字；
  - 紧随的段落或列表块，左侧外挂伪元素：
    - 人类：`border-left: 2px solid oklch(72% 0.14 75); padding-left: 12px;`（琥珀金）；
    - Agent：`border-left: 2px solid oklch(62% 0.16 280); padding-left: 12px;`（紫靛）；
  - 平常不加任何背景底色，保持 100% 白底黑字清爽感；鼠标悬停段落时，在发丝线顶角淡入极小胶囊 `👤 人类` / `🤖 Agent`（字号 10px，透明度 0.6）。

### 4. 彻底重构底栏：极简静默设计
- **废除**：完全移除粗糙的“标记/取消”按钮、移除 3 个彩色圆点、移除突兀亮紫方块按钮！
- **自动防抖保存**：文本停止输入 800ms 后自动静默保存；
- **微状态呈现**：底栏左侧仅显示一行极简小灰字：`✓ 已自动保存 (15:30)`；未保存时显示 `● 正在同步...`；
- **浮动选区气泡（Floating Bubble）**：选中文本时，在光标正上方 8px 处平滑浮出轻磨砂微胶囊：`[重点] [便签] [复制]`，不选时不占任何屏幕像素。

---

## 三、方案优缺点总结
- **优点**：视觉噪音降到最低，像 Apple Notes / Notion 一样高级沉浸；自由拖拽极度跟手；彻底告别任何刺眼色块。
- **适用场景**：重度文字记录、思路沉淀、不需要密集操作的深度思考者。
