> **灵感来源**：Obsidian、VS Code Minimal、Typora Split Mode  
> **设计哲学**：**“源码与渲染实时双向映照，高密度创作者与审阅利器”**  
> **对应分支**：`ui-exp-split-pro`

## 二、关键组件与交互规格

### 1. 视图模式切换器（三段式分段器）
- 顶栏中央提供三态快速切换：
  - `[ 单栏编辑 ]`：专注码字，左侧编辑区全屏展示；
  - `[ 双栏对照 ]`：左侧代码 + 右侧实时渲染，同步滚动（Scroll Sync）；
  - `[ 纯预览 ]`：纯净最终呈现模式，方便一口气阅读通览。

### 2. 多重发丝分割手柄（Dual Splitters）
- 界面内包含两条自由拖拽手柄：
  1. **编辑区 vs 预览区 分割线**：用户可任意左右按需分配编辑与预览的宽度（默认 1:1）；
  2. **主区域 vs 资料包 分割线**：无级控制资料包宽度（0px ~ 400px，同样支持吸附收起与双击快速折叠）。

### 3. 人机笔迹的双向映射呈现
- **源码区（左）**：原样呈现干净的 `<!-- @author: human -->` 注释，语法高亮呈浅灰色，不打扰阅读；
- **渲染区（右）**：
  - 自动将注释转化为高质感 Callout 协作卡片；
  - 人类文字使用琥珀金描边与微暖底色，Agent 使用紫靛描边与微冷底色；
  - 真正做到了“左边改源码，右边立刻看到协作卡片的漂亮排版”。

### 4. 协作统计底栏（Collab Status Bar）
- **底部状态行（紧凑 26px）**：
  - 显示人机协作贡献占比（如 `👤 人类 35% | 🤖 Agent 65%`）；
  - 显示实时字符数与行数；
  - 右侧显示平滑保存状态灯，支持静默自动保存。

## 三、方案优缺点总结
- **优点**：最强大的审阅与撰写体验；实时所见即所得；完美契合“人机共同整理一篇深度文档”的高阶工作流。
- **适用场景**：方案深度撰写、专利交底书整理、重度文档协作与复杂排版。
