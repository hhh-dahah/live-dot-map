## 二、关键组件与交互规格

### 1. 顶栏：微交互分段滑块（Smooth Segmented Control）
- **顶栏控件**：
  - 弃用粗糙的纯文字切换，采用带 150ms 阻尼滑块的胶囊切换器：`[ 编辑 | 预览 ]`；
  - 切换时背景滑块平滑横向滑动，手感极其细腻。
- **展开/全屏按钮**：
  - 顶部右侧增加 `[ ⤢ 专注模式 ]` 按钮，点击后抽屉临时扩宽到 85vw，专注深度编写。

### 2. 资料包栏：精工发丝分割器（Tactile Splitter）
- **手柄视觉**：
  - 分割线宽度 5px，中央有 3 个微小的发丝导向盲文点（`⋮`）；
  - 拖拽时在手柄上方浮出即时宽度气泡（如 `240px`）；
  - **自由拉伸**：无级在 `0px ~ 500px` 随意调节；
  - **磁吸与双击**：向右拖至 `<60px` 自动 Snap 到 0px，双击在当前与 0px 间来回切换。

### 3. 人机笔迹识别卡片化渲染
- **视觉规格**：
  - **人类段落**：
    - 左边框：`border-left: 2.5px solid #D97706;`（Amber 琥珀金）；
    - 卡片背景：`background: rgba(245, 158, 11, 0.025); border-radius: 0 6px 6px 0;`
    - 卡片顶栏：小徽标 `👤 人类 · 刚刚`（11px，字重 500，颜色 `--brand-amber`）；
  - **Agent 段落**：
    - 左边框：`border-left: 2.5px solid #6366F1;`（Indigo 紫靛）；
    - 卡片背景：`background: rgba(99, 102, 241, 0.02); border-radius: 0 6px 6px 0;`
    - 卡片顶栏：小徽标 `🤖 Agent · 自动沉淀`（11px，字重 500，颜色 `--brand-indigo`）；
  - **优雅度**：段落之间界限分明，即便文档极其冗长，扫一眼也能清晰看出哪些是人类要求、哪些是 Agent 回答。

### 4. 底栏：Linear 级深墨操作胶囊与状态组
- **状态区（左侧）**：
  - 微型连接绿点（带有 2s 一次的呼吸动画）；
  - 显示当前保存时间与字数统计（如 `1,420 字 · 已同步`）；
- **操作区（右侧）**：
  - 彻底干掉大亮紫矩形；
  - 换为 **Linear 风格深墨冷岩灰按钮**（`#18181B` 近纯黑底、白色文字、6px 优雅倒角、顶部 1px 发丝微亮边、微量按压位移反馈）；
  - 内容未变更时呈**幽灵禁用态**（淡灰不抢眼），内容有改动时优雅亮起。

## 三、方案优缺点总结
- **优点**：质感极其高级，工业感与精细感拉满；状态与操作分区明确；段落人机归属一眼可辨。
- **适用场景**：追求高效、结构化任务推进，注重操作反馈与工具高级质感的团队。
