## 计划

### 1. n7a 「打开所在文件夹」直达文件
- 病根：`src/bridge/editor-service.mjs` 把文件路径降成所在目录；`installer/winforms/Program.cs` OpenFolder 只支持目录。
- 修法：文件目标用 `explorer.exe /select,<文件>`（固定参数），目录保持现状。

### 2. n7b 编辑器快捷保存 Ctrl+S / Ctrl+Enter
- 病根：showMdEditor 只有保存按钮；全局 Ctrl+S 会触发导出地图。
- 修法：编辑器内拦 Ctrl+S/Ctrl+Enter（stopPropagation 防冒泡），直接触发保存；footer 加常驻提示。

### 3. n7c 未保存 ≠ 冲突灯
- 病根：setStatus 状态表未定义 dirty，未知状态兜底成红色「异常」。
- 修法：补 dirty（黄「待保存」）；编辑器内显示「未保存」提示，不动全局灯；真冲突保持红。

### 4. n9 检索不到节点名字
- 病根：retrieveContext 种子匹配只有 query.includes(name)，名字是 query 超集时miss。
- 修法：名称双向匹配（name.includes(query) 也进 seeds）；name 词元权重高于正文。先写复现测试。

### 5. n12 agent 不得改人类原话
- 病根：map_write_markdown 整文替换无护栏。
- 修法：服务端守卫——删除旧非空行且未传 allowContentRemoval 则拒绝，引导用 map_append_markdown；同步协议文档。
