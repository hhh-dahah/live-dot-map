## 验收复测修复记录（2026-08-30 第二轮）

用户复测发现「点击节点连面板都没有」，自查确认为两个真 bug，均已修复并验证。

### Bug 1：rail 收起态残留导致面板只显示 36px 细边条
- **现象**：localStorage 存了 `dock-rail=1`（用户曾手动收起侧栏）时，点击节点面板只以细边条出现，看起来像「没有面板」。
- **修法**：`renderPanel()` 增加 `expandRail()`——只要存在选中对象（`S.sel` 非空或 mdSession 在），就摘掉 `rail` 类并把 `dock-rail` 偏好重置为 `'0'`。
- **验证**：预设 rail=1 → 点节点 → 面板正常展开 320px，`dock-rail` 被重置为 0。

### Bug 2：画布点节点绕过未保存守卫
- **现象**：节点 pointerup 分支直接写 `S.sel` 再 rAF 延迟渲染，完全绕过 `select()` 里的 mdSession 脏检查——编辑文档到一半点别的节点，不弹确认框，选中静默切换，编辑器里还留着旧文档，状态错乱。
- **修法**：
  1. `select(kind, id, defer = false)` 加第三参，`defer=true` 时 `requestAnimationFrame(() => { render(); renderPanel(); })`，确认框回调里的递归调用透传该参数。
  2. 画布节点点击分支改为走 `select('node', id, true)`（defer 保 DOM 稳定，不吞后续 click/dblclick）。
- **验证（Playwright 实测，桥 v18）**：
  - 脏状态点别的节点 → 弹「有未保存的修改…继续编辑/放弃并切换」✓（截图 `走查截图/p1/p1-fix-01-脏切换守卫.png`）
  - 「继续编辑」→ 弹窗关闭、编辑器与内容保留、选中不变 ✓
  - 「放弃并切换」→ 编辑器关闭、面板切到目标节点详情 ✓
  - 干净状态切换 → 无弹窗、静默回详情 ✓
  - 编辑中点同一节点 → 不弹框、编辑器不动（幂等）✓
