# 公开发布门禁

## 背景
内部 RC 可运行不等于可以切换公开下载入口；公开发布还需要平台、签名、线上一致性和普通用户证据。

## 当时考虑
将产品开发和自动测试与公开分发旁路推进；没有签名、Release/Store 入口、三源 200/hash 一致性和真实客户端证据时，只标记为内部 RC。

## 结果
公开门禁仍未全部通过，当前不会把内部安装包宣称为正式公开版本。

## 当前意义
这是主线人工验收之后的下一层问题节点。

## 下一步
完成 Claude Code 与 WorkBuddy 桌面生命周期、普通小白全流程、三源一致性、可追溯 tag、签名和 Store/Release 门禁。
