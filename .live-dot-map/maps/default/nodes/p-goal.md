# 活点地图 v2

## 背景
这是项目总目标：把复杂项目中的目标、问题、尝试、失败、证据和人类判断，压缩成一张人和 Agent 都能读写的探索地图。

## 当时考虑
地图要表达探索结构，不做通用白板、聊天客户端或 Jira 替代品；事实放在项目目录的 map.json 与 Markdown 分片中；协作本地优先、不上传项目内容，并保留人对归档、整理和路线判断的最终决定权。

## 结果
形成自研单文件画布、本地桥、map.json v2、Markdown 详情和 Agent Skill/MCP 的产品路线。

## 当前意义
这是技术路线、协议记忆、协作分发三条支线的共同来源；项目已从实现阶段进入人工验收。
