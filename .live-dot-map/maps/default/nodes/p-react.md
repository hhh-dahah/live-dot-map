# ReactFlow 验证 Demo

## 背景
早期用 ReactFlow 快速验证节点、路线和连接是否能表达项目探索过程。

## 当时考虑
ReactFlow 能快速得到可交互图编辑器，适合验证探索语义，但当时就不是最终架构。

## 结果
完成验证后废弃；代码位于上级 live-dot-map，不再维护、不迁移，只保留数据示例参考。

## 失败原因
不适合承载单文件 HTML、项目内 map.json、Markdown 分片、本地桥和自定义协作协议；继续维护会把验证框架误当成产品底座。

## 当前意义
这条红色支线说明早期 Demo 没有被直接包装成正式产品。
