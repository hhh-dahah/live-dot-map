# 协议与记忆底座

## 背景
项目从画布交互转向人和 Agent 共享探索记忆后，需要可靠文件协议和统一写入边界。

## 当时考虑
用 map.json 做可读索引、Markdown 做详情；本地桥作为唯一可靠写入者，负责 WAL、原子保存、冲突、恢复、事件、检索和 Agent 权限；人类标注与 Agent ack 必须可审计。

## 结果
map.json v2、Markdown 分片、本地桥、MCP/Hook、确定性图检索、记忆策展 V1、可信 actor、人类审批边界和多地图目录均已实现并纳入测试。

## 当前意义
这是产品从 Demo 成为共享探索记忆层的核心转折。

## 下一步
用真实高层目标验收 Agent 是否能自主控制记录粒度、判断失败并回溯；保持历史证据可见、判断权归人。
