## 核心功能（5 块，模仿 Excalidraw「演示文稿 / 协作工作空间 / 评论」的写法）

### 1. 探索地图
项目的每一步都画在一张图上——做过的尝试、走过的弯路、还没解决的问题，打开就能看到全貌。

### 2. 记忆策展
地图只留下此刻最重要的事，冗余的细节收进文件。Agent 每次打开都从重点开始，不被无关信息拖慢。

### 3. 快速切换
换一个项目，不必开新对话。地图跟着切换，Agent 接上之前的记忆继续往下做。

### 4. 节点引用
把地图上的一个节点发给 Agent，它就知道你在说哪件事。当时的判断、试过的方案、失败的原因，都在那里。

### 5. 人机协作
你在地图上标注、修改，Agent 把新的想法和结果写回图里。你们看到的，始终是同一张图。

## 关键差异说明（为什么这版才对）

| 上一版（机味） | 这一版（Excalidraw 味） | 差在哪 |
|---|---|---|
| 项目记忆，一眼看见 | 探索地图 | 去掉对仗口号，用名词 |
| 只记重点，拒绝噪音 | 记忆策展 + 一句「只留下最重要的，细节收进文件」 | 喊口号 → 说事实 |
| 你写，它读；它做，你审 | 人机协作 + 一句「你们看到的始终是同一张图」 | 对仗排比 → 平静陈述 |
| Alpha 徽章「核心功能已可用」 | 「还缺少什么？来 GitHub 看路线图」 | 生硬声明 → 开放邀请 |

**Excalidraw 语感三原则**：
1. 标题用**名词**（探索地图、记忆策展、快速切换），不是口号
2. 说明用**一句陈述**把能力讲透，语气像产品文档，平静克制
3. 结尾用「还有更多…… + 引导行动 + 公开路线图」，把「未完成」转成「开放」
