# 真实用户实测清单（2026-08-09）

> 目的：由**真人**（您）以真实用户视角完整走一遍产品链路——发现、下载、首次使用、画布操作、文件夹直连、Agent 接入——把不好用的地方全部挑出来，之后逐个修。
> 使用方式：按顺序执行每一阶段；每步给出「操作 / 挑刺点」。发现任何不对劲，随时停下，按文末模板记录问题（附截图更好），不必做完所有步骤。
> 前置准备：① 推荐用**无痕窗口**（模拟全新用户，不受旧缓存/旧授权干扰）；② 准备一个测试文件夹（如 `D:\桌面\测试-活点地图\`，放一个随便什么文本文件模拟项目）；③ 打开一个记事本用于粘贴验证复制内容；④ 截图像素不足时用 Win+Shift+S 截局部。

## 阶段 1：发现（约 5 分钟）—— landing 首页

| # | 操作 | 挑刺点 |
|---|------|--------|
| 1.1 | 无痕窗口打开 `https://app.live-dot-map.workers.dev` | 第一屏 3 秒内能说出「这是干嘛的、对我有什么用」吗？标题「行车记录仪」比喻会不会让人困惑？副标题够直白吗？ |
| 1.2 | 从顶到底完整滚动一遍页面 | 每个区块文案看得懂吗？「演示 GIF 待补充」占位符会不会显得半成品、影响信任？有没有错别字/标点（注意全角半角混用）/排版瑕疵？ |
| 1.3 | 点导航「功能」「接入」「说明」三个链接 | 「说明」页打开后能否一键返回落地页？内容是否图文清晰？ |
| 1.4 | 点「复制接入协议」，粘贴到记事本 | 复制出来的是完整的协议段吗（应有「活点地图」标题 + 会话开始铁律等小节）？前后有没有多余空白？ |

| # | 操作 | 挑刺点 |

## 阶段 3：画布玩一遍（约 10 分钟）—— 不连文件夹，纯演示模式

| # | 操作 | 挑刺点 |
|---|------|--------|
| 3.1 | 演示地图上拖拽节点、平移、滚轮缩放 | 手感流畅吗？有没有卡顿/跳变/缩放锚点怪异？ |
| 3.2 | 按 N 新建节点，双击改名 | 圆随文字适配吗？名字太长会怎样？ |
| 3.3 | 按 L 从节点拉出方案线：悬空、拖端点吸附另一节点 | 吸附判定灵敏吗？线名怎么改？ |
| 3.4 | 选中方案线切换绿/红/灰三态 | 颜色/线型区分明显吗？切换后连接有没有被破坏？ |
| 3.5 | 按 M 建便签：挂节点上、挂线上 | 便签编辑/避让/移动体验如何？ |
| 3.6 | 选中对象看属性面板：方案线打分（0–100）、归档按钮 | 评分输入顺手吗？归档后线变淡了、悬停失效——符合直觉吗？如何取消归档？ |
| 3.7 | 右键节点/线，点「打开 Markdown」 | 未连文件夹时行为友好吗？（应有降级提示而不是报错） |
| 3.8 | 删除一个节点 | 连着的线怎么处理？级联删除干净吗？能撤销回来吗？ |
| 3.9 | 连续做几次操作，Ctrl+Z 撤销、重做 | 撤销/重做是否完整、有没有丢便签/丢线的情况？ |
| 3.10 | 演示模式下改动几下 | 有没有出现「改动只在本页」的提示？提示出现时机合理吗？ |
| 3.11 | 导出 map.json，用记事本打开 | JSON 合法吗？字段（routes/nodes/edges/anns）直观吗？ |
| 3.12 | 改动后刷新页面 | 演示模式改动丢失（预期内）——但作为新用户，**会不会觉得「我画的东西没了」是 bug**？这一步的困惑程度请重点记录。 |

## 阶段 4：文件夹直连与同步（约 15 分钟）—— 核心价值

| # | 操作 | 挑刺点 |
|---|------|--------|
| 4.1 | 准备测试文件夹 `D:\桌面\测试-活点地图\`，里面放一个 txt | — |
| 4.2 | 画布菜单 →「打开项目文件夹」→ 选该文件夹 | 弹了什么确认框？文案清楚吗？（无 map.json 时应询问是否创建） |
| 4.3 | 确认后去资源管理器看该文件夹 | 是否生成了 `.live-dot-map/map.json`？用记事本打开看内容（应有主路线 + 开始节点 + 今日日期） |
| 4.4 | 画布上建 2–3 个节点、拉线、加便签 | 左上角状态点变化（保存中 → 已同步）正常吗？不用刷新，直接切到记事本看 map.json 是否实时更新？ |
| 4.5 | 模拟 Agent 改文件：手动在 map.json 里改一个节点名或加一条便签，保存 | 回到画布，2 秒内是否自动刷新出新内容？（等不到就记问题） |
| 4.6 | 节点右键 →「打开 Markdown」 | 内置查看器打开了吗？md 文件创建在哪、内容模板完整吗？ |
| 4.7 | 给节点改名 | map.json 里对应的 md 路径是否跟着变？有没有残留旧文件？ |
| 4.8 | 关掉浏览器 → 重新双击 app.html | 是否自动重连上次的文件夹（不用重新选）？有没有弹授权请求？体验顺不顺？ |
| 4.9 | 把 map.json 从文件夹拖进画布 | 拖拽导入成功吗？高亮反馈明显吗？ |
| 4.10 | 随便造一个假 `.json`（如 `{"foo":1}`）拖进画布 | 报错信息友好吗？（预期应提示格式不对且不动原图） |
| 4.11 | 拔网线/断网状态下打开 app.html 和操作 | 离线还能用吗？会不会卡在加载或弹网络错误？ |

## 阶段 5：Agent 接入（可选，约 10 分钟）—— 手头有 Agent 就做

| 级别 | 含义 | 例子 |
|------|------|------|
| P0 | 流程走不通 / 数据损坏 / 崩溃 | 下载不了、保存丢数据、打开报错 |
