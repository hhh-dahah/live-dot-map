> 日期：2026-08-10。依据：`docs/真实用户实测记录.md` 意见 1–12、`docs/架构修改计划.md`（技术栈与部署链路以其为准，本文不重复）、2026-08-10 用户三项决策。

## 页面结构（对标 plus.excalidraw.com 布局）

1. **顶导**：左 logo（字号/排版参照 Excalidraw）+ 右侧菜单（功能 / 接入 / 说明 / GitHub 星标按钮 / 「打开画布」CTA）。滚动模糊底+描边。
2. **Hero**：
   - 主标题「人机协作 变得简单」（56px / 600 / `#030064`，「协作」二字带浅绿高亮底）
   - 副标题「探索 记录 回忆 · 一切尽在 livedotmap」（18px / `#030064`）
   - 黄色星标按钮（`#FFE599` 底、`#705400` 边框、hover 黄→白、跳 GitHub 仓库）+ 主 CTA
   - 超大产品截图：去除意见 6 的怪框，按意见 7 做成 Excalidraw 式超大展示（接近视口宽、轻薄边框或无框、大圆角、柔和投影）
   - 背景 `#F9FFF9` + 手绘彩色线条/小圆点/四角小标签装饰（意见 5，Framer Motion 微浮动，reduced-motion 降级）
3. **一键接入区**：保持现有单按钮设计（已完成，不重做），样式对齐新视觉；去掉页面上残留技术细节（意见 8/9）。
4. **功能演示区**：4 张大尺寸演示卡（16:10 占位框按大图规格，标题+一句话说明）。现有 3 张（建节点拉方案线 / 便签评分归档 / 与 Agent 共享一张图）+ 新增第 4 张「打开项目文件夹，自动同步」。
5. **本地优先区**：目录树区块保留，排版对齐新视觉。
6. **底部 CTA**：手写风标题 + 一个按钮 + 一句说明，极简（意见 9）。
7. **页脚**（意见 12，新增）：深色背景 + 手绘线条装饰；左侧 logo + MIT 说明；右侧链接列（功能 / 接入 / 说明页 / GitHub）。

## 执行步骤（技术细节按架构修改计划）

1. `landing/` 脚手架（Next.js、TypeScript、App Router、无 src/）+ Motion；`next.config.ts` 静态导出。
2. `globals.css` 维护 landing 专用令牌，并将 Excalidraw 实测色补充到 `brand-spec.md`。
3. 逐 section 移植/重写组件（Nav / Hero / AnimatedMap / JoinSteps / Features / LocalFirst / BottomCTA / Footer / Reveal），先静态跑通核对文案链接。
4. 动效层：Hero 装饰微动画、whileInView stagger、星标按钮 hover 黄→白、复制成功微交互、Nav 滚动态；全部包 `prefers-reduced-motion` 降级。
5. `npm run build` → `sync-deploy.mjs` 增量同步 `.deploy/`（保留 app.html、agent-kit/ 等既有文件）→ 本地 serve 走查。
6. Playwright 三断点（1280/768/375）截图到 `走查截图/阶段7-landing-*`，逐条对照「验收对照表」。
7. 文档同步：implement.md（阶段 7 记录）、AGENTS.md（landing/ 结构+构建命令）、brand-spec.md（令牌映射+补充色）、.gitignore（landing 构建产物）；sw.js CACHE bump v3。
8. **用户确认后**三源部署：push master（EdgeOne 自动更新）+ `wrangler deploy` + CloudBase 上传；验证三个公网 URL。
