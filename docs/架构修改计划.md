# 架构修改计划：landing 重写为 Next.js（大厂感动效版）

> 阶段 7 计划。背景：landing.html 为 653 行零依赖单文件，交互仅有复制按钮/平滑滚动/导航滚动态，无动效。决策：landing 全面重写为现代前端工程，对标大厂落地页动效（参考 plus.excalidraw.com，已考证其为 Next.js，首页 `_next/` 资源引用 ×173）。

## 技术栈定案

- **Next.js（App Router）+ TypeScript** —— `output: 'export'` 纯静态导出（部署是 Cloudflare Workers 静态资产，无 Node 服务器；SSR/ISR 不可用也不需要，SSG 对落地页即最优）。
- **Tailwind CSS** —— `brand-spec.md` 的 OKLch 令牌映射进 theme，不改令牌值。
- **Framer Motion（motion 包）** —— 动效核心。
- **shadcn/ui —— 不引**：落地页无表单/弹窗/表格类需求，按钮卡片自写更贴品牌；后续做应用型页面再引。
- **MDX —— 暂缓**：尚无文档/博客多页内容，有需要再启用。

红线遵守：`app.html` 不动（保持单文件零依赖双击即用）；新依赖理由记入 `implement.md`；文案简体中文；绿/红/灰仅用于方案线与徽标。

## 工程结构

- 新建子目录 `landing/`（create-next-app：TS、Tailwind、App Router、ESLint；不用 src/），根目录现有文件全部不动。
- `landing/next.config.ts`：`output: 'export'`、`images.unoptimized: true`、`trailingSlash: true`。
- 组件拆分（`landing/app/page.tsx` 组装）：
  - `components/Nav.tsx` —— 滚动态（模糊底+描边）、锚点平滑滚动
  - `components/Hero.tsx` + `components/AnimatedMap.tsx` —— 见动效清单
  - `components/JoinSteps.tsx` —— 三步接入卡 + 复制按钮（含成功微交互）
  - `components/Features.tsx` —— 三个演示卡（GIF 占位保留，结构化为后续录屏替换）
  - `components/LocalFirst.tsx` —— 目录树区块
  - `components/BottomCTA.tsx`、`components/Footer.tsx`
  - `components/Reveal.tsx` —— 通用 whileInView stagger 包装
- 内容/文案原样移植自 `landing.html` 343–479 行；接入协议 fallback 文本来自 `landing.html` 内 `script#snippet-fallback`（源文件是 `docs/agent-protocol.md`，不手改逻辑，只移植既有文本）。
- 复制逻辑保持现状语义：`fetch('/agent-kit/AGENTS.snippet.md')` 失败回落内嵌文本；`navigator.clipboard` + legacy `execCommand` 双通道。

## 动效清单（Framer Motion）

- Hero `AnimatedMap`：内联 SVG 迷你活点地图——节点 scale-in stagger 点亮、方案线 `pathLength` 延伸动画、状态徽标 pop、待机循环微动画；下方保留真实拍图（`assets/landing-hero.png`）。
- 各 section：`whileInView` + staggerChildren 进入动效（y 位移+透明度，cubic-bezier 缓动，viewport once）。
- 按钮：hover/active 缩放与阴影微交互；复制成功后文案变「✓ 已复制」并带勾形弹出。
- Nav：滚动阈值切换 `backdrop-blur` + 底描边。
- 全部动效包 `prefers-reduced-motion` 降级（motion 的 `useReducedMotion`）。

## 部署链路（已定：留在 Cloudflare）

- 决策记录：继续用 Cloudflare Workers 静态资产托管，不迁 Vercel。原因：静态导出模式下 Vercel 的 SSR/边缘能力用不上；`vercel.app` 国内不可达会打断 Agent 拉取 `agent-kit/setup.md` 的口令链路；现有 CF 主 + CloudBase 备双点架构已跑通，域名不可换。
- 构建：`cd landing && npm run build` → 产物 `landing/out/`。
- 同步脚本 `landing/scripts/sync-deploy.mjs`（node 写，跨平台）：把 `out/` 内容**增量覆盖**进 `.deploy/`，保留 `.deploy/` 既有独立文件（`app.html`、`agent-kit/`、`assets/`、`icons/`、`sw.js`、`manifest.webmanifest`、`favicon.ico`、`_headers`）；`out/index.html` 覆盖 `.deploy/index.html`。
- `wrangler.toml` 不变；`_headers` 追加（可选优化）：`/_next/static/*` → `Cache-Control: public, max-age=31536000, immutable`。
- `sw.js`：`CACHE` 由 `live-dot-map-v2` bump 到 `v3`（首页内容大变，触发旧缓存清理；策略本身不用改）。
- 明确权衡：landing 从此需要构建，本地预览用 `npx serve .deploy` 或 `wrangler dev`，不再双击即用（`app.html` 不受影响）。
- 自动部署（2026-08-12 已落地）：未用 Workers Builds，改 GitHub Actions（`.github/workflows/deploy.yml`）——push master 且 `.deploy/` 变更即自动部署 CF；CloudBase 同流水线（需配 TCB 密钥，详见 implement.md 阶段 8 补丁 3）。
- 上线：走查通过后、经用户确认再 `wrangler deploy`。

## 执行步骤

1. `landing/` 脚手架（create-next-app）+ 装 framer-motion；配 `next.config.ts` 静态导出。
2. Tailwind theme 映射品牌令牌；全局样式（字体栈、wrap、基础排版）。
3. 移植全部 section 组件（先静态无动效跑通，逐屏核对文案与链接）。
4. 加动效层（AnimatedMap + Reveal + 微交互 + reduced-motion 降级）。
5. `npm run build` → 同步 `.deploy` → 本地 serve 走查（1280/768/375 三断点；复制按钮双通道；fetch fallback 断网验证）。
6. Playwright 截图到 `走查截图/`（阶段7-landing-*）人工核对。
7. 文档四处同步（implement.md / AGENTS.md / brand-spec.md / .gitignore）。
8. 用户确认后 `wrangler deploy` 上线并验证公网 URL。
