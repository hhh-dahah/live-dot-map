## 一、作品简介（约 480 字）

**项目名称**：活点地图（多 Agent 协同的共享探索记忆层）

**问题与场景**：Agent 在长程任务中的协作状态散落在聊天记录里——方案分叉后难以比较，失败原因随会话淡忘，更换 Agent 必须重新解释；多 Agent 并行时，各自执行、结果无法统一验证，执行证据难以沉淀与审计。

**核心解决方案**：以本地 `map.json` 索引与 Markdown 分片为单一事实源，用节点（目标/问题/结果）、方案线（成功/失败/待验证三态）、路线与里程碑表达探索结构。人通过画布操作，Agent 通过统一命令层读写同一份记忆——10 个固定 MCP 工具 + 官方 Skill + 四套适配器（Claude Code、Codex、Kimi Code、CodeBuddy），执行结果实时回写画布。

**创新点与差异化**：① 局部上下文寻址：任何节点、方案、路线一键复制引用交给 Agent，无需重述项目上下文；② 失败资产化：失败方案不删除、可归档，验证工具强制每次尝试留下证据、失败原因与评分；③ 判断权在人：删除仅限人类、里程碑需人工审核、WAL 全量审计，Agent 无法越权。

**开放/复用价值**：Agent 无关的文件协议与命令层，新平台只需写适配器；同一套机制可迁移至研发协同、智能运维、智能客服等任意复杂任务闭环。

**当前进展**：v2 核心完成——本地桥 WAL/冲突/恢复、多地图、四套适配器落地，真实 Codex 长程任务闭环验收通过（2026-08）；正在推进多 Agent 协作与更多平台适配。
