- **现状**：`editNodeName`（`app.html:1449`）设 `inlineNodeEdit` 后渲染跳过重建（`:997`），节点 DOM 被 `:986` 清空 → 圆圈消失只剩裸输入框。

  - [ ] 手测：改长名/短名提交后圆半径自适应

### ✅ 1.4 问题 4：counters 钳制自愈
- **现状**：保存永不同步 counters（`src/web/bridge-client.ts:61-64`），`deserialize`（`app.html:2263-2266`）盲信过期 counters → 刷新/同步后 id/名称回退撞号（拖上面动下面、重名「新节点1」）。
- **改成**：`deserialize` 把所有计数器钳到 ≥ 数据推导值：`nextNum = max(c.num, 最大num+1, 最大id后缀+1)`，`nextNodeName = max(c.nodeName, 「新节点N」最大N+1, 节点数+1)`；edge/ann/edgeName/routeName 同理。（协议层 set_counters 二期可选，不做。）
- **验收**：
  - [x] 新增单测：过期 counters 的 map.json 反序列化后 nextNum/nextNodeName/nextEdge 全部 ≥ 推导值（`tests/web/counters-clamp.test.mjs`，4 条全过）
  - [ ] 手测：在已有 n4/新节点3 的地图上刷新 → 新建节点编号/名称不重复
  - [ ] 手测：e1~e8 已存在时再拉线不撞 e1

### ✅ 1.5 问题 3：自绘十字准星
- **现状**：本机系统 crosshair/text 细线光标几乎不可见（实机 `output/cursor-test.html` 验证），箭头/节点工具空白处用 crosshair → 光标"消失"。
