## 二、构建提示词（复制给任意 Agent）

### A. 构建 Windows 安装包（一行入口）

> **提示词**：
> 克隆 https://github.com/hhh-dahah/live-dot-map 到临时目录，`npm install` 后依次执行 `npm run build`、`npm run build:sea`、`npm run build:windows-installer`。构建成功后做两件事：① 把 `dist/windows-installer/LiveDotMapSetup.exe` 压缩为 `LiveDotMapSetup.zip`；② 汇报两个产物的完整路径与 SHA256。不要改动任何源码。

**前置环境**：Node ≥ 20（本机 v24.15.0）· npm 11 · .NET 8 SDK（本机 8.0.421）
**产物路径**：
- 完整安装包：`dist/windows-installer/LiveDotMapSetup.exe`（约 162MB）
- 桥本体：`.deploy/livedot-bridge-win-x64.exe`（SEA，约 88MB）
- 网页版：`app.html`（单文件，双击即用，降级模式）

### B. 发布 GitHub Release（一行入口）

> **提示词**：
> 构建完成后，用 gh CLI 发布到 https://github.com/hhh-dahah/live-dot-map 的 Releases：
> `gh release create v2.0.0 dist/windows-installer/LiveDotMapSetup.zip dist/windows-installer/LiveDotMapSetup.exe --title "v2.0.0" --notes "包含 8-16 全部修复：…" --repo hhh-dahah/live-dot-map`
> 发布后汇报 Release 页面 URL 与附件清单。

### C. 轻量版（开发者自取依赖，不打包 npm）

> **提示词**：
> 从仓库根目录取 `app.html`、`livedot.mjs`、`agent-kit/`、`docs/map-json-v2.md`、`docs/agent-protocol.md` 打包为 `live-dot-map-轻量版.zip`（几 MB），不包含任何 node_modules 与构建产物。README 说明：开发者解压后双击 `app.html` 即用（纯浏览器降级模式）；要完整 Agent 协作请按 AGENTS.md 接入本地桥。
