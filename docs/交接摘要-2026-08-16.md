# 活点地图 交接摘要（2026-08-16）

## 项目是什么
人和 Agent 共享的探索地图：节点写目的/结果，方案线记尝试（绿=走通、红=失败、灰=待验证），数据存项目 `.live-dot-map/map.json`（v2 协议）。本地桥 `livedot.mjs` 提供 loopback 服务 + WAL 并发保护；Windows 安装器 WinForms 单 exe（~154MB SEA）。
