为什么不一样

地图,不是文档容器

画布只保留结构和状态。详细背景、尝试过程和结论,继续留在本地 Markdown。

探索,不是任务管理

没有截止日期、负责人和固定流程。探索允许失败、回退、悬空和新的问题路线。

Agent 原生,不是 AI 按钮

Agent 与人共同操作地图:创建节点、建立路线、更新方案状态、维护 Markdown。

三种方案状态

状态属于方案线,不属于节点。

成功

方案已走通,实线连接结果节点。

失败

方案已证伪,虚线悬空,记录保留。

待验证

方案未确认,点线悬空,等待结论。

本地优先

地图数据和 Markdown 位于本地项目目录。离线可用,不要求登录账号,不要求云数据库。

Codex、Claude Code、Cursor、Gemini CLI 等 Agent 通过项目文件读写同一张地图。不同 Agent,同一份地图。

项目目录/ ├── MAP.html # 地图入口 ├── MAP.md # 地图说明与项目概览 ├── nodes/ # 节点详情 ├── routes/ # 路线与方案记录 └── AGENTS.md # 项目级 Agent 指令
